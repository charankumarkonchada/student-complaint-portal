As a team member, you are assigned specific feature files for the IntelliHostel project. You do **not** need to clone the repository or push branches to GitHub. Follow this simple file-based workflow:

---

## 📋 General Rules for All Members

1. **Receive Assigned Files:** Receive your assigned feature folder from **K. Charankumar** (`TEAM_FILE_DISTRIBUTION/<YOUR_NAME>/`).
2. **Modify ONLY Your Assigned Files:** Work only on the routes, templates, CSS, and JS files provided in your package.
3. **Never Modify Shared Infrastructure:** You will not receive and must not touch shared files (`app.py`, `config.py`, database code, services, ML engine, or `base.html`).
4. **Do NOT Rename Files:** Keep exact file names (e.g., `add_complaint.py`, `admin_login.html`, etc.) so they integrate cleanly.
5. **Do NOT Change Folder Structure:** Keep files in their relative subdirectories (`routes/...`, `templates/...`, `static/css/...`, `static/js/...`).
6. **Do NOT Delete Files:** Keep all provided files intact.
7. **Do NOT Send the Entire Project:** Never send a full project ZIP or files belonging to another member.
8. **Send ONLY Completed Assigned Files:** When finished, send back only your assigned folder/files to K. Charankumar.
9. **Specify What Files Were Changed:** Provide a brief note listing the exact files you edited.
10. **State What Was Tested:** Describe the actions you took to test and verify your changes.
