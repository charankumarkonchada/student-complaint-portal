# Data Flow Diagrams (DFD)

This directory stores Data Flow Diagrams (DFD) for the IntelliHostel Student Complaint Portal.

## Contents
- Level 0 (Context Diagram)
- Level 1 (Major subsystems: Auth, Complaints, Common Issues, ML, Notifications)
- Level 2 (Detailed complaint handling and admin triage flows)

Supported formats: `.drawio`, `.png`, `.svg`.
